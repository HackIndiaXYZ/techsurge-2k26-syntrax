# SYNTRAX - PS-F03 Architecture Knowledge Base

SYNTRAX is preparing a documentation-first prototype for TechSurge 2K26 / Kalachakra problem PS-F03, **Autonomous Parametric Climate Insurance & Instant Settlement Engine**. This repository currently contains no product implementation: it is the agreed plan for building a safe, simulated telemetry-to-payout demo in the 17-hour engineering window.

Start with [Project Memory](docs/PROJECT_MEMORY.md), then use the [Knowledge Base Index](docs/00_INDEX.md). The canonical source for policy, telemetry, consensus, payout, wallet, and audit definitions is [Canonical Domain Model](docs/database/DATA_MODEL.md).

The proposed MVP uses public or synthetic weather inputs, synthetic policyholders and wallets, and simulated payouts only. It does not use real money, accounts, UPI, insurer integrations, proprietary feeds, or make regulatory or production-readiness claims.
