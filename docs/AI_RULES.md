# AI Rules

Strict rules for AI coding agents working in this repository:

1. Inspect before modifying.
2. Never invent requirements.
3. Never overwrite unrelated work.
4. Respect Git branches.
5. Check existing code before creating new abstractions.
6. Prefer simple solutions during the hackathon.
7. Do not add dependencies without justification.
8. Do not expose secrets.
9. Keep interfaces explicit.
10. Update documentation when architecture changes.
11. Run relevant tests/build checks after meaningful changes.
12. Report files changed.
13. Report commands executed.
14. Report unresolved issues.
15. Never silently make architectural decisions that affect another teammate.
16. Prefer deterministic structured outputs for AI where applicable.
17. Do not introduce agents/RAG/vector databases merely because they are available.
