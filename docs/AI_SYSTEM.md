## AI Architecture Template

- **Model/Provider:** Target AI models (e.g., Gemini).
- **Prompts:** Strategy for prompt management.
- **Structured Outputs:** Using JSON schema for reliable parsing.
- **Tool Calling:** How the AI interacts with the system.
- **Retrieval:** Strategy for fetching context.
- **Embeddings:** Model for generating embeddings (if needed).
- **Vector Database:** Storage for embeddings (if needed).
- **RAG:** Retrieval-Augmented Generation approach.
- **Agents:** Autonomous or semi-autonomous agents.
- **Orchestration:** Managing multi-step AI workflows.
- **Memory:** Context retention between interactions.
- **Guardrails:** Ensuring safe and relevant AI outputs.
- **Fallback Models/Providers:** Redundancy strategy.
- **Evaluation:** Measuring AI response quality.
- **Logging:** Tracking AI interactions for debugging.
- **Cost Control:** Monitoring and limiting API usage.
