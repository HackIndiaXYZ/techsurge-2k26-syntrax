# AI Context Protocol

If optional explanation is added, pass a compact, immutable context object: `correlation_id`, policy ID/version, consensus state/value/member IDs, trigger outcome/reason, payout state/transaction ID, and known limitations. Do not pass hidden instructions, real personal data, secrets, raw database credentials, or authority to decide outcomes.

Store the deterministic source records, not the generated prose, as the audit authority. Generated output is disposable UI assistance.
