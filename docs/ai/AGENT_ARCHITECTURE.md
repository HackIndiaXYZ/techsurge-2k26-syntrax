# Agent Architecture

**Status: not applicable to the core MVP.** A tool-using autonomous agent adds latency, non-determinism, and authority-management work without helping the required telemetry-to-payout proof. The backend services are ordinary deterministic modules, not agents.

Optional future operator assistance can be a read-only retrieval-and-explanation assistant over approved documentation and audit projections. It has no write tools and cannot independently contact providers, execute payments, or alter policy rules.
