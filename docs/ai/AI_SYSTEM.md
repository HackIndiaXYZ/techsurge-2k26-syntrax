# PS-F03 AI System Status

**Status: optional support only; not an MVP dependency.** The system can be complete and competitive without an AI model because the PS demands explainable, deterministic adjudication and settlement. Sanju’s MVP contribution is a labelled synthetic scenario set and review of the deterministic boundary.

If time remains, an explanation endpoint may transform stored facts into plain language, for example: “Sources A and B agreed at 101.5 mm; source C was rejected for disagreement; the 100 mm policy threshold was met.” It must cite record IDs, never invent facts, and never receive an action tool that changes payout state.
