# MCP Strategy

**Status: not applicable to the PS-F03 MVP.** Model Context Protocol integration is not needed to ingest seeded telemetry, compute consensus, evaluate a static policy, or operate a synthetic ledger. Adding it would introduce tool authorization and reliability work unrelated to the organizer’s required path.

If a future documentation assistant uses MCP, it must expose only read-only project/reference retrieval and comply with the same no-payment-authority boundary.
