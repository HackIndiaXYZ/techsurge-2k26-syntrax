# Optional Explanation Prompting Guidelines

Prompt only from an approved deterministic record bundle. Require an explanation to state source values, rejected-source reason, consensus value/state, exact policy threshold/window, trigger outcome, payout state, and synthetic-money limitation. Instruct it to say “not available” rather than infer a missing fact.

Do not ask a model whether to pay, how much to pay, which source to trust, or how to bypass validation. The output must be clearly labelled generated and replaceable by a fixed template.
