## Template

- **Entities:** Table Name (e.g., `Users`)
- **Fields:** Column Names
- **Types:** Data Types (e.g., `VARCHAR`, `INTEGER`)
- **Primary Keys:** Unique identifier (e.g., `id`)
- **Foreign Keys:** Relationships to other tables
- **Indexes:** Columns to index for performance
- **Relationships:** 1:1, 1:N, N:M
- **Constraints:** `NOT NULL`, `UNIQUE`
- **RLS/Security Considerations:** Row Level Security policies
- **Migration Strategy:** How schema changes will be applied (e.g., Alembic, Prisma)
