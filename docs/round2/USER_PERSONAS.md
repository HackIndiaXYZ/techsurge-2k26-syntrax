# PS-F03 Prototype Personas

All identities are synthetic fixtures, not real insurance customers.

| Persona | Need | MVP screen |
| --- | --- | --- |
| Synthetic smallholder policyholder | Understand whether a predefined rainfall condition paid and why | Policy, wallet and settlement evidence |
| Demo operator | Run known telemetry and failure scenarios without hand-editing data | Simulation controls and system dashboard |
| Judge or reviewer | Verify corruption handling, deterministic decision, latency and no duplicate payout | Source comparison, audit log and metric view |
| Future insurer operator | Understand the production gap without mistaking the demo for a licensed product | Limitations and audit trace |
