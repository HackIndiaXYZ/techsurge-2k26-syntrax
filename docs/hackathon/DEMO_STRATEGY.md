# PS-F03 Demo Strategy

Lead with a single question: “Why did this synthetic policyholder receive this simulated payout?” The page answers visually in order: active policy, incoming sources, validation, consensus, deterministic trigger, payout, wallet transaction, audit and latency.

Use only seeded data. First show the corrupt-source preview and explain the rejected value. Next show a fresh active clean-trigger scenario. Finally simulate a retry with the same idempotency key and highlight one transaction. Keep the synthetic/no-real-money and basis-risk statements visible.
