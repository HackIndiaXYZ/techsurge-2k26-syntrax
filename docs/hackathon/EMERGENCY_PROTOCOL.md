# Demo Emergency Protocol

If a deployed service fails, switch to the same seeded local stack and preserve the declared synthetic scope. If data appears inconsistent, reset only via the documented fixture/reset route, state that the prior run is invalid, and rerun from a fresh correlation ID. Do not hand-edit a wallet balance, hide a rejection, invent latency, or substitute a manual payout. Keep screenshots or a recorded successful local run only as secondary evidence, not as a live result.
