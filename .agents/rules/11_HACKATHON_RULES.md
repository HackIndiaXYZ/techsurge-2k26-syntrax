# PS-F03 Hackathon Rules

1. Preserve the 17-hour plan: build telemetry-to-audit first, then test/rehearse, then optional polish.
2. Do not add real money, rails, blockchain, Kafka, complex cloud architecture, production insurance infrastructure or autonomous agents.
3. Escalate a schema, idempotency, seed, test or deployment blocker immediately; choose a documented safe fallback.
4. Keep the demo honest: synthetic-only, measured not fabricated, and explicit about basis risk and production gaps.
